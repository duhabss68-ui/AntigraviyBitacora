# MiAula Slate 2.15.0 · CETIS

Control docente offline PWA para Educación Media Superior (CETIS).
Desarrollado para trabajo docente diario: pase de lista por horas, libreta de calificaciones, rubros, Proyecto o Examen por parcial, rúbricas de evaluación, ruleta, equipos persistentes, bitácora de seguimiento, puntos extra y exportación a Excel / reportes PDF.

## Versión
- **Versión:** MiAula Slate 2.15.0 · CETIS
- **Dispositivo:** Huawei MatePad 12X (diseño horizontal) y navegadores modernos.
- **Tecnología:** HTML5, Vanilla JavaScript, CSS Tokens, IndexedDB (`MiAulaMobileDB` v3), Service Worker offline.

## Configuración de GitHub Pages
Para publicar esta versión como PWA:
1. En GitHub, ve a **Settings** → **Pages**.
2. En **Build and deployment** → **Branch**, selecciona `main` y `/ (root)`.
3. Guarda los cambios. Tu app estará disponible en:
   `https://duhabss68-ui.github.io/AntigraviyBitacora/index.html`
